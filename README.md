# FORMA — Архитектура и дизайн интерьера

Концептуальный сайт архитектурного бюро FORMA. Современный минималистичный дизайн, адаптивная вёрстка и интерактивные элементы.

**Демо:** https://soulwound.github.io/forma-architecture/

## О проекте

FORMA — учебный проект сайта архитектурного бюро, созданный для демонстрации навыков frontend-разработки.

Основная задача — разработать эстетичный и функциональный сайт-визитку с акцентом на архитектурную фотографию, типографику и удобство взаимодействия с пользователем.

## Возможности

- Современный минималистичный дизайн
- Адаптивная вёрстка для мобильных устройств и компьютеров
- Мобильная навигация
- Плавная прокрутка страниц
- Анимации появления элементов
- Параллакс-эффект изображений
- Индивидуальная стилизация элементов формы
- Форма обратной связи с отправкой заявок на электронную почту
- Согласие на обработку персональных данных
- Локальное хранение изображений

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- EmailJS
- Google Fonts
- GitHub Pages
